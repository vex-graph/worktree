# Primeagen — Personal Standalone R5 CLI

Lives at `personal/primeagen`, outside the ecosystem tree. Python owns cold CLI
policy/host adapters; a C23 binding consumes actual Harness Message and API Haven
request envelopes. Func is an independent tool, not an embedded VM. This initial
implementation is not production-ready or a completed R4 Harness agent.

## Scheduled Determinant consumer integration

The next terminal cycle migrates reusable rendering/widgets/input/command pieces
to Determinant R3 while keeping conversation, draft, consent, pipes and terminal
ownership resident in the Primeagen host. First reproduce the user-reported
restart-required `/update` defect, then prove an actual view/command change in
the same production process with rejected-candidate preservation and rollback.
Foundation extraction or callback-substitution tests do not fix or prove this
consumer seam. Physical appearance remains user acceptance; no live model call
is implicitly authorized. Future Semicolon R6 integration consumes Primeagen,
never reverses that dependency.
